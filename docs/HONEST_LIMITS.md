# Honest limits

This project is deliberately honest about what it does and does not show. Keeping these
boundaries explicit is a feature, carried over from the Faultiva design philosophy.

## What is real
- The fault catalogues are generated by our own stuck-at fault simulator
  (`endee_vlsi/faultsim.py`) on standard ISCAS-85 benchmark circuits. Nothing is faked.
- Every catalogued fault localizes correctly through Endee (c432 366/366, c880 833/833).
- The noise-tolerance chart is measured, not asserted (`endee_vlsi/noise_experiment.py`).

## Localization returns a SET, never a forced single site
Faults that produce identical outputs under the test patterns are **physically
indistinguishable** from the response alone. The pipeline returns the whole candidate set
and always prints its size. It never truncates a set to look decisive. `AMBIGUOUS` is an
honest verdict, not a failure.

## A clean verdict does not prove a fault-free circuit
`FAULT_FREE` means the observed behaviour matched golden **on the applied test patterns**.
Faults undetected by those patterns are, by construction, not catalogued and not claimed.
Detection quality is bounded by test-pattern coverage.

## Scale and tool-choice honesty
- At hundreds-to-thousands of vectors, a plain in-memory nearest-neighbour scan would also
  work; a vector database is more than this size strictly requires.
- Graceful degradation under noise is a property of **approximate nearest-neighbour search
  in general**, not of Endee specifically — the same curve would appear on FAISS/Qdrant.
  The result validates the retrieval **paradigm**, not a unique Endee capability.
- The Endee-specific value appears at **scale** (chip-family / fab-corpus = millions–
  billions of behaviour vectors) and at the **edge** (offline/air-gapped tester-side
  diagnosis). This project is the first step toward that regime, not a demonstration of it.

## What this is NOT
- Not a replacement for Faultiva. Faultiva is Pavan's full DL detection/localization
  system; this is a focused retrieval application that generalizes its fault-dictionary
  idea onto a vector database.
- Not endorsed by or affiliated with Endee.
